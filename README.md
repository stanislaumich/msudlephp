==============================================
MSUDLE PHP — Платформа дистанционного обучения
==============================================

Проект создан на основе архитектуры Django-версии MSUDLE, переписан на PHP 8.0+ без использования ORM.

==============================================
ТЕХНОЛОГИИ
==============================================

- PHP 7.4+
- MySQL / MariaDB
- Bootstrap 5.3 (через CDN)
- PDO для работы с базой данных

==============================================
УСТАНОВКА
==============================================

1. Настройте базу данных в .env:
   DB_DRIVER=mysql
   DB_HOST=localhost
   DB_NAME=msudle
   DB_USER=root
   DB_PASS=

2. Импортируйте схему:
   mysql -u root -p msudle < sql/schema.sql

3. Настройте виртуальный хост или используйте встроенный сервер PHP:
   cd public
   php -S localhost:8000 router.php

4. Откройте браузер:
   http://localhost:8000

==============================================
АРХИТЕКТУРА
==============================================

Пользователи:
- Студенты: модель Student (логин, пароль, ФИО, группа)
- Сотрудники: модель User (Django-style auth_user)

Роли:
- TEACHER — базовый преподаватель
- ADMIN — администратор (is_superuser)
- UMO — УМО / Ректорат
- DEAN — Декан
- HEAD — Завкафедрой

Активная роль хранится в сессии. Все проверки прав идут через getActiveRole().

- Testing — тесты, вопросы, варианты ответов
- Chat — личные и групповые чаты
- Accounts — преподаватели, группы, права
